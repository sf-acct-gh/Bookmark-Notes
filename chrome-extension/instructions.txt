Bookmark Notes Browser — Chrome extension
==========================================

This extension lets you browse your Bookmark Notes workspaces, sections, and
bookmarks from the Chrome toolbar, and jump to one with a click. It is
read-only — it never writes anything back to your Bookmark Notes app. All
edits still happen in the normal web interface.

It works entirely from a cached copy of your bookmarks, refreshed
periodically in the background — it does NOT contact your server every time
you open the popup.


STEP 1 — Point it at your own Bookmark Notes data
--------------------------------------------------
Open:
    import-to-chrome/config.js

and change this line near the top to your own export URL:
    const BOOKMARKS_URL = 'https://opentools.cudacan.com/bookmarknotes/api/export';

This should be the same URL you'd use to download a full backup (e.g. via
`curl <your-url>`) — it returns the full workspaces/sections/bookmarks JSON.
It must be an https:// (or http:// for local testing) URL.


STEP 2 — Update the matching permission in the manifest
--------------------------------------------------------
Open:
    import-to-chrome/manifest.json

and find this line:
    "host_permissions": ["https://opentools.cudacan.com/*"]

Change the domain to match whatever URL you put in STEP 1 (just the
scheme + host, e.g. "https://your-domain.example/*"). This is what lets the
extension actually reach your server — Chrome blocks the request otherwise.


STEP 3 — Install it in Chrome
------------------------------
1. Open chrome://extensions in Chrome.
2. Turn on "Developer mode" (toggle, usually top-right).
3. Click "Load unpacked".
4. Select the `import-to-chrome` folder (the one containing
   manifest.json).
5. The "Bookmark Notes Browser" icon should now appear in your toolbar.
   You may need to click the puzzle-piece icon in the toolbar and "pin" it
   to keep it visible.

(Need to hand this folder to someone else, or just keep a tidy copy
somewhere? Chrome can't install directly from a .zip — that's only possible
for extensions published on the Chrome Web Store — but zipping it up is a
fine way to move it around; they'd just unzip it and do the same "Load
unpacked" steps above. From inside this `chrome-extension` folder:
    zip -r import-to-chrome.zip import-to-chrome
)

Click the icon any time to browse: Workspaces -> a workspace's sections ->
a section's bookmarks. Click a bookmark to open it in the current tab.
Click the small "ⓘ" next to a bookmark to see its full URL and notes in a
details panel that slides in from the right — click the "←" there to slide
back. Use the ⟳ button in the popup to force an immediate refresh instead
of waiting for the automatic one (every 6 hours).


Troubleshooting
----------------
- "Bookmarks are not available yet..." — the extension has never
  successfully downloaded your data. Double check the URL in config.js is
  correct and reachable, and that the host_permissions domain in
  manifest.json matches it exactly, then reload the extension
  (chrome://extensions -> the reload icon on this extension's card).
- Changed config.js or manifest.json after installing? You need to reload
  the extension (chrome://extensions -> reload icon) for the change to take
  effect — just refreshing the popup isn't enough for manifest changes.
